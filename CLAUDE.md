# Сайт ПМП-Интерком

Одностраничный сайт компании ООО «ПМП-Интерком» (системы безопасности, Санкт-Петербург).
Весь сайт — один файл `index.html` (стили и скрипты внутри), без сборки.

## Правила по текстам
- Не писать отзывы от имени клиентов.
- Не писать «предоставим документы по запросу».
- Язык сайта — русский, тон деловой, без канцелярита.

## Дизайн
- Две темы: светлая (слоновая кость) и тёмная (графит), единственный акцент — латунь.
  Все цвета — в начале `<style>`: сначала палитра `--c-*`, затем роли (`--bg`, `--text`, `--accent`...)
  для светлой темы в `:root` и для тёмной в `:root[data-theme="dark"]`. В остальном CSS — только роли,
  никаких цветов напрямую.
- Тема: выбор пользователя в `localStorage` (`pmp-theme`), иначе системная настройка.
  Скрипт в `<head>` ставит `data-theme` до отрисовки — его нельзя переносить вниз.
- В светлой теме нет тёмных блоков: чередование светлое/тёмное при прокрутке утомляет глаза
  (заказчику не нравится). Разделы различаются только мягким чередованием `--bg` и `--bg-alt`.
- Подача: один блок — один вопрос посетителя, главное видно сразу, подробности — в раскрывающихся
  блоках (`details.acc`), а не удаляются. Тексты короткие: тезис в одну строку, без абзацев-подводок.
  Одни и те же факты (лицензия, 24/7, 15 минут) не повторять по всей странице.
- Сайт только информационный: клиент находит сайт и звонит по телефону. Никаких форм, заявок
  и сбора данных — все призывы к действию ведут на звонок (`tel:+78123004030`).
  Не писать «оставьте заявку», «перезвоним» и подобное.
- Структура: первый экран (заголовок до 8 слов, подзаголовок, одна кнопка с номером телефона, чертёж) →
  полоса заказчиков → 01 Услуги → 02 Как это работает → 03 О компании (цифры, доводы, лицензия) →
  04 Этапы → 05 Вопросы → 06 Контакты (крупный телефон, адреса, карта). На телефоне внизу — панель «Позвонить».
- Сетка: 12 колонок (`.grid`), разделы пронумерованы 01–06: подпись `.idx` в колонках 1–3,
  заголовок с колонки 4. Минимум рамок и карточек — держимся на воздухе и тонких линиях.
- Кнопка — чернильная, латунь заливает её при наведении. Без градиентов и свечения.
- Типографика: после коротких слов и перед тире — неразрывный пробел; составные слова через дефис
  оборачиваются в `<span class="nw">`, чтобы не рвались на переносе.
- Нумерация: арабские «01», «02»… простым латунным текстом, без рамок, римских цифр и курсива.
  В этапах — контурные цифры `.bnum`, наполняются латунью при прокрутке.
- Динамика сдержанная (только мышь, отключается при `prefers-reduced-motion`): `.aura` — мягкое свечение
  за курсором поверх страницы (без подсветки блоков прямоугольником — заказчику это не нравится),
  наклон чертежа. Кольцо-курсор, магнитные кнопки, перелив в заголовках, бегущая строка
  и полоса прогресса убраны намеренно — не возвращать без согласования.
- Услуги — строки с крупным названием и одной строкой описания, подробности раскрываются по клику.
  Заказчики — неподвижная сетка 4×2 (на телефоне 2 колонки), все равнозначны.
- Для неспециалистов объясняем простыми словами: схема «Как работает система» в три шага,
  нормы, оборудование и варианты подключения — в раскрывающихся блоках с понятными подписями,
  сокращения расшифрованы («Напрямую в МЧС (ЦУКС, ФПС)»).
- В селекторах вида `.x span` использовать `.x > span`: внутри текста бывают `<span class="nw">`.
- Анимации: `.tr` — заголовок раскрывается шторкой, `.fd` — плавное появление;
  всё отключается при `prefers-reduced-motion`.
  Скрывать контент до анимации — только значениями, которые понимают все браузеры
  (никаких отрицательных `inset()` в `clip-path`), и всегда с запасной проверкой при прокрутке,
  иначе в Safari/Firefox заголовки останутся невидимыми.
- Контраст текста — не ниже WCAG AA (4.5:1, для крупного 3:1) в обеих темах.
- Шрифты: Onest (основной), Cormorant Garamond italic (акцентные слова в заголовках, тег `<em>`).
  Шрифты встроены в `index.html` (base64 в `@font-face`), не подключать их снова через Google Fonts.
- Крупные цифры в карточках задавать от ширины карточки (`cqi`), а не окна, иначе они вылезают за край.
